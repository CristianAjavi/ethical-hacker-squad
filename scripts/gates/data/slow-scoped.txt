# Controls that cost more than the path which runs on every push allows.
#
# WHY THIS FILE EXISTS AT ALL
#     This list was written first as a literal inside scripts/gates/run-all.sh,
#     and that was wrong within one push: scripts/run-batteries.sh is a SECOND
#     runner - CI calls it as a step of its own - and it discovers every
#     *.selftest.sh in the tree by convention. It never saw the literal, so the
#     313 s battery it was meant to keep off the push path ran there anyway.
#     run-batteries.sh says it in its own header: two paths to the same effect
#     with different reach is how a green comes to mean something other than it
#     looks like. The list lives here once, and both runners read it.
#
# THE BAR
#     ~30 s is what this repository allows on the path that runs on every push;
#     gate-budget-ledger.sh cites the figure in its own header and the `gates`
#     job takes 45 s today. A control above that does not get quietly dropped -
#     it gets a job of its own in ci.yml and its name printed, in every run that
#     skips it, with the reason and the command that runs it.
#
# NOT A TOLERANCE
#     Nothing here is excused from measurement. Everything here is measured
#     somewhere else, and both runners name it out loud rather than passing it
#     over in silence. EHS_SLOW_GATES=1 runs them wherever you are.
#
# One file name per line. Blank lines and #-comments ignored.

# 301 s: it settles a quoted case count by running the twenty batteries it
# cites. ci.yml job `counts`.
gate-case-counts.sh

# 313 s: its own battery carries a control over the real tree, so it costs the
# same as the gate. Declaring only the gate would have moved the cost into
# --selftests instead of removing it. ci.yml job `counts`.
