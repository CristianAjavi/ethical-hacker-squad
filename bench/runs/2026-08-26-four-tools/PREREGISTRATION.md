# Pre-registration — the four tools together, against the band that has held six times

Written and pushed **before any arm runs and before this file's author has seen the corpus**.

## Why this round

Six rounds have each moved one lever and each fell short. The last one measured why: on defects
where no single file is wrong, both products lose four in ten, and the gap belongs to the field.
Four deterministic joins now ship — `log_escaper`, `path_coverage`, `default_resolver`,
`writer_parity` — each built for a shape measured in the misses, and each measured **alone**:
+3.1 points, one flag, two of four shapes, one true positive.

**Their combined effect has never been measured**, and that is what the band actually asks.

## The band, unchanged for the seventh time

- **Supported** — recall exceeds `mantis`'s by **≥ 5 points** *and* the decoy rate is **not
  higher**.
- **Refuted** if `mantis`'s recall is greater than or equal to ours.
- **Inconclusive** if ahead by less than 5.

Failed six times, twice on each half, lowered once from 15 with the lowering declared on the
page, never raised. It stays.

## The corpus, and the thing this round could most easily cheat at

The brief asks for composition defects across **at least eight distinct mechanisms, none
accounting for more than four defects** — deliberately including shapes no shipped tool
addresses: a cache keyed on less than authorization depends on, a schema validating the request
but not the message the worker consumes, an ACL at the proxy while another layer is reachable
directly, a permission checked on create but not on delete.

**Commissioning a corpus that matches the tools would be building the exam to fit the pupil.**
It is written by an author instructed not to read this project's procedures, and the brief was
written before the tools' combined effect was known. The key records `mechanism` per defect, so
the spread is checkable rather than claimed.

## Registered, with the discrimination check that the fourth round failed after the fact

> If **either** arm's reach exceeds **90%** of the planted defects, this corpus does not
> discriminate and the round reports that instead of a comparison.

## Registered secondary, without a band

**Recall by mechanism, per arm** — including recall on the mechanisms **no tool addresses**. If
this project leads only on the shapes its tools cover and matches elsewhere, the tools work and
the lead is narrow and bought; if it leads on shapes no tool covers, something other than the
tools is doing it and the tools are not the explanation. That distinction is the one thing this
round can establish that no previous one could.

Also registered: `tools_run` and `from_tool` per finding, so the share of findings that came
from a tool rather than a reading is measured rather than assumed.

## Scoring and multiplicity

`../2026-08-26-coverage-rules/score.py`, unchanged, with `--sensitivity`; `adapt.py` over every
arm with no per-arm branch; floor of 3 valid runs. Four runs per arm. Both arms under the
artifact contract. One round, then this corpus is retired.
